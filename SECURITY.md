# Security Policy

## Supported versions

LawnDart is pre-1.0. Security fixes land on `main` and ship in the next
published package version.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Email **security@sellistix.com** with:

- A description of the issue and its impact
- Steps to reproduce, or a proof of concept if you have one
- Affected package names and versions, if known

You should receive an acknowledgement within 5 business days. We will work with
you on a fix and a coordinated disclosure date.

## Scope

This policy covers the published LawnDart NuGet packages and this repository's
source. It does not cover third-party stores, hosts, or applications that
consume LawnDart.
